# Парсер цитат с bashorg.рф

Парсер лучших цитат с сайта башорг.рф. Извлекает текст цитат с сохранением форматирования и сохраняет в текстовый файл.

## Что делает

- Скачивает главную страницу bashorg.рф
- Извлекает текст всех цитат со страницы
- Сохраняет переносы строк (заменяет `<br>` на `\n`)
- Сохраняет результат в файл с разделителями между цитатами

## Требования

- Python 3.7+
- Библиотеки: `requests`, `beautifulsoup4`

## Установка

```bash
pip install requests beautifulsoup4
